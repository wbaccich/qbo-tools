Privacy Policy

WB QBO Tools · Effective November 9, 2026

WB QBO Tools is a private, internal reporting tool operated by Will Baccich. It is not offered to the public, and it connects only to QuickBooks Online companies that its operator manages and is authorized to access.

What the tool accesses

With the explicit approval of an administrator of each connected QuickBooks Online company, the tool reads accounting data — such as accounts, customers, invoices, payments and financial reports — through Intuit's QuickBooks Online Accounting API. Access is read-only: the tool does not create, change or delete anything in QuickBooks.

How data is used and stored

  • Data is used only to produce internal reports for the connected companies.
  • Data is processed and stored only on the operator's own computer. It is not uploaded to any server or cloud service run by this tool.
  • Data is never sold, rented or shared with third parties, and is not used for advertising.
  • Sign-in credentials issued by Intuit (access and refresh tokens) are stored in the operator's operating-system credential store, not in files or source code.

Disconnecting

Any administrator of a connected company can disconnect the tool at any time in QuickBooks Online (Apps → Connected apps). Once disconnected, the tool can no longer read that company's data.
